Manual Específico de Instalación y Desinstalación en Windows

Guía técnica exhaustiva que detalla todos los pormenores de aprovisionamiento, despliegue, auditoría, migración segura y baja limpia del Sistema Congreso ETS 2026 en Microsoft Windows 10 y Windows 11 (64-bit).

Windows 10 / Windows 11 (x64) PostgreSQL 14 / 15 / 16 / 17 Node.js LTS (npm.cmd seguro) Desinstalación Asistida con Resguardo SQL

1. Requisitos de Infraestructura y Prerrequisitos de Software

La plataforma está diseñada para ejecutarse de forma nativa sobre Windows sin requerir subsistemas pesados como Docker o WSL2, garantizando máxima velocidad y mínimo consumo de memoria.

Componente Requisito Mínimo Recomendado para Producción
Sistema Operativo Windows 10 Home/Pro (64-bit) Versión 21H2+ Windows 10 / 11 Pro o Windows Server 2022 (x64)
Procesador (CPU) Intel Core i3 / AMD Ryzen 3 (2.0 GHz, 4 núcleos) Intel Core i5 / AMD Ryzen 5 o superior (6+ núcleos)
Memoria RAM 4 GB de memoria física 8 GB o 16 GB (para compilación y escaneo simultáneo)
Almacenamiento 3 GB de espacio libre en disco (SSD recomendado) 10 GB libres para resguardos (backups) y logs

Software Obligatorio Previo

  1. Node.js LTS (Versión 18.18.0 o superior; recomendado v20.x, v22.x o v24.x LTS):
    Descarga oficial: https://nodejs.org/es/download.
    Importante: En el asistente de instalación de Windows, marque la casilla "Add to PATH" para que los comandos de terminal se reconozcan globalmente.
  2. NPM Package Manager (v10.x o superior):
    Se incluye y enlaza de forma automática con el paquete oficial de Node.js.
  3. PostgreSQL Database Server (Versión 14, 15, 16 o 17 para Windows x64):
    Descarga oficial (EnterpriseDB): https://www.enterprisedb.com/downloads/postgres-postgresql-downloads.
    Durante la instalación, registre la contraseña asignada al superusuario postgres y verifique el puerto de escucha (habitualmente 5432 o 5433).
  4. Git for Windows (Opcional recomendado - v2.x):
    Descarga oficial: https://git-scm.com/download/win.

2. Preparación del Entorno Windows

2.1 Política de Ejecución de PowerShell (ExecutionPolicy)

Por defecto, Windows restringe la ejecución de scripts .ps1. El instalador autónomo y todos los lanzadores por lote (.bat) resuelven esto de forma nativa invocando PowerShell con el parámetro -ExecutionPolicy Bypass, por lo que no es necesario degradar la directiva de seguridad global del sistema operativo.

2.2 Permisos de Ejecución (Usuario Local vs Administrador)

Instalación Flexible: Si instala en una carpeta de usuario (como C:\CongresoETS2026 o D:\Sistemas\Congreso), puede ejecutar Instalar_CongresoETS2026.bat con doble clic directo. Si decide instalar dentro de carpetas protegidas como C:\Program Files, haga clic derecho y seleccione "Ejecutar como administrador".

2.3 Configuración de Red y Firewall de Windows Defender

Para permitir que las estaciones de acreditación móviles (celulares y tablets en la puerta mediante la PWA /pwa-operador) se comuniquen con el servidor del congreso en la red local (LAN / Wi-Fi del predio):

# Ejecutar en PowerShell como Administrador para habilitar puertos 3000 y 4000 en la red local:
New-NetFirewallRule -DisplayName "Congreso ETS 2026 - Frontend" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow
New-NetFirewallRule -DisplayName "Congreso ETS 2026 - Backend API" -Direction Inbound -LocalPort 4000 -Protocol TCP -Action Allow

3. Proceso de Instalación Paso a Paso

El instalador está programado para ser 100% independiente de rutas absolutas. Puede ejecutarse desde un pendrive USB, disco externo o carpeta descargada.

  1. Lanzamiento del Asistente:

    Haga doble clic en el archivo raíz:

    Instalar_CongresoETS2026.bat

    El lanzador inicializa la consola en codificación UTF-8 para garantizar que todos los caracteres y acentos se visualicen correctamente.

  2. Auditoría Diagnóstica en Tiempo Real:

    Antes de modificar ningún archivo, el instalador inspecciona los servicios locales y despliega una tabla de diagnóstico:

     ==========================================================================
   ESTADO DE SERVICIOS Y PRERREQUISITOS DEL SISTEMA                        
 ==========================================================================

 [ OK       ] Node.js Runtime              : Instalado (v24.21.0)
 [ OK       ] NPM Package Manager          : Instalado (v11.19.0)
 [ OK       ] PostgreSQL Database          : Instalado y activo en puerto 5433
 [ OK       ] Git for Windows (Opcional)   : Instalado (v2.55.0)
 [ OK       ] Puertos Web (3000 / 4000)    : Puertos 3000 y 4000 disponibles

    Si falta Node.js o el servicio de PostgreSQL está detenido, el asistente ofrece un menú interactivo para abrir los instaladores o la consola de servicios (services.msc) con tecla de re-evaluación inmediata [R].

  3. Selección de Directorio Destino:

    El asistente abre un selector gráfico de carpetas de Windows (Folder Browser Dialog). La ruta predeterminada sugerida es C:\CongresoETS2026. El instalador normaliza comillas, barras finales y realiza una prueba de escritura antes de avanzar.

  4. Despliegue Limpio de Componentes:

    Mediante un copiado selectivo con robocopy, se transfieren los módulos de Backend, Frontend, scripts y manuales excluyendo de forma estricta node_modules, cachés temporales de Next.js y archivos de entorno antiguos.

  5. Asistente de Base de Datos PostgreSQL:

    El instalador solicita confirmar el Host (localhost), Puerto (detecta automáticamente si es 5432 o 5433), Usuario (postgres) y Contraseña:

    • Si la base no existe: Crea congreso_ets2026 con codificación UTF-8, aplica el esquema relacional de 26 entidades (schema_3fn.sql) y los datos semilla (seed.sql).
    • Si la base ya existe (actualización): Conserva el 100% de los datos existentes y ejecuta de forma idempotente la rutina reparar_integridad.sql para anexar columnas faltantes (como capacidad_maxima en puntos_acceso) y sincronizar secuencias.
  6. Generación de Entorno y Claves Criptográficas:

    El instalador genera automáticamente los archivos de configuración local:

    • backend\.env: Con la cadena de conexión protegida, una clave simétrica AES-256-CBC de 32 bytes (64 caracteres hexadecimales) de alta entropía para cifrado de códigos QR, y el secreto de tareas programadas (CRON_SECRET).
    • frontend\.env.local: Con la URL base enlazada al Backend API (http://localhost:4000).
  7. Instalación de Paquetes y Compilación:

    Ejecuta npm.cmd install --no-audit --no-fund para resolver paquetes sin bloqueos de directiva de script. Luego compila TypeScript en Backend (dist/server.js) y Next.js en Frontend (.next/).

  8. Creación de Accesos Directos:

    Genera en el Escritorio del usuario el acceso directo oficial Congreso ETS 2026.lnk apuntando al lanzador de la plataforma.

4. Control y Operación Diaria

Una vez completada la instalación, la administración cotidiana se realiza mediante los accesos directos por lote provistos en la raíz:

Script por Lote Propósito Operativo Comportamiento
Iniciar_Congreso.bat Arranque general de la plataforma Inicia Backend (4000), Frontend (3000), espera la disponibilidad en red y abre el navegador en http://localhost:3000.
Detener_Congreso.bat Detención limpia de servicios Localiza los identificadores de proceso (PIDs) que ocupan los puertos 3000 y 4000 y los finaliza sin dejar instancias en memoria.
Revisar_Servicios.bat Diagnóstico en caliente Audita Node.js, NPM, PostgreSQL y ejecuta un Smoke Test HTTP contra /health y el portal web.
Reparar_BaseDatos.bat Integridad referencial y aforos Verifica y repara columnas ausentes, valida que las capacidades de recintos cubran los cupos y resincroniza secuencias.
Desinstalar_Congreso.bat Baja controlada del sistema Asistente interactivo de desinstalación con opción de backup preventivo y remoción de base de datos.

5. Procedimiento de Actualización e Idempotencia

Principio de Idempotencia: Ejecutar el instalador sobre una carpeta o base de datos preexistente NO destruye ni borra los datos operativos de asistentes o acreditaciones.

Cuando se requiere actualizar la plataforma a una versión más reciente (por ejemplo, incorporando nuevas funcionalidades de aforo, tematización o reparaciones de base de datos):

  1. Detenga la plataforma ejecutando Detener_Congreso.bat.
  2. Ejecute el nuevo instalador Instalar_CongresoETS2026.bat indicando la misma carpeta de destino.
  3. El asistente actualizará los archivos de código fuente, mantendrá los parámetros en .env y disparará automáticamente la rutina reparar_integridad.sql en PostgreSQL, asegurando que cualquier nueva columna se agregue sin truncar las tablas.
  4. Vuelva a iniciar la plataforma con Iniciar_Congreso.bat.

6. Procedimiento Completo de Desinstalación del Sistema

La desinstalación del sistema puede realizarse en cualquier momento de manera ordenada, evitando dejar servicios colgados o residuos en disco.

6.1 Método Asistido: Desinstalar_Congreso.bat

Haga doble clic en el archivo ubicado en la carpeta del sistema:

Desinstalar_Congreso.bat

Fases del Asistente de Desinstalación:

  1. Confirmación Inicial: Solicita al operador confirmación explícita (S/N) para prevenir ejecuciones accidentales.
  2. Detención de Procesos: Libera los puertos web 3000 y 4000 cerrando de forma segura las instancias de Node.js asociadas.
  3. Resguardo Preventivo Opcional (Backup SQL): Pregunta si desea generar un respaldo de seguridad previo. Si responde S, invoca pg_dump y almacena el archivo completo backup_previo_desinstalacion_[fecha].sql en el Escritorio de Windows.
  4. Gestión de PostgreSQL: Pregunta si desea eliminar la base de datos congreso_ets2026. Si se confirma, desconecta los clientes concurrentes con pg_terminate_backend y ejecuta DROP DATABASE. Si responde N, la base queda almacenada intacta en PostgreSQL.
  5. Remoción de Accesos Directos: Elimina el acceso directo Congreso ETS 2026.lnk del Escritorio.
  6. Cierre y Eliminación Física: Concluye informando que los servicios fueron dados de baja y que puede borrarse la carpeta contenedora.

7. Desinstalación Manual Paso a Paso (Vía Terminal)

Si un administrador de sistemas requiere automatizar la baja mediante scripts desatendidos de PowerShell o CMD:

Paso 1: Detener los servicios en ejecución

# Detener procesos en puertos 3000 y 4000:
$puertos = @(3000, 4000)
foreach ($p in $puertos) {
    Get-NetTCPConnection -LocalPort $p -State Listen -ErrorAction SilentlyContinue | ForEach-Object {
        Stop-Process -Id $_.OwningProcess -Force
    }
}

Paso 2: Generar Backup de Resguardo (Opcional)

set PGPASSWORD=tu_password_postgres
pg_dump -h localhost -p 5432 -U postgres -d congreso_ets2026 -F p -f "%USERPROFILE%\Desktop\backup_seguridad_congreso.sql"
set PGPASSWORD=

Paso 3: Eliminar la Base de Datos PostgreSQL

set PGPASSWORD=tu_password_postgres
psql -h localhost -p 5432 -U postgres -d postgres -c "SELECT pg_terminate_backend(pid) FROM pg_stat_activity WHERE datname = 'congreso_ets2026' AND pid <> pg_backend_pid();"
psql -h localhost -p 5432 -U postgres -d postgres -c "DROP DATABASE IF EXISTS congreso_ets2026;"
set PGPASSWORD=

Paso 4: Eliminar Accesos Directos del Escritorio

Remove-Item -Path "$([Environment]::GetFolderPath('Desktop'))\Congreso ETS 2026.lnk" -Force -ErrorAction SilentlyContinue

Paso 5: Eliminar el Directorio Físico

# Reemplazar con la ruta donde fue instalado:
Remove-Item -Path "C:\CongresoETS2026" -Recurse -Force

Paso 6: Nota sobre Motores Compartidos (Node.js y PostgreSQL)

Preservación de Prerrequisitos: Node.js y PostgreSQL son motores compartidos que pueden albergar otros desarrollos o bases de datos en la máquina. Por esta razón, el desinstalador no los desinstala. Si desea retirarlos por completo del equipo, hágalo desde Configuración de Windows -> Aplicaciones instaladas.

8. Matriz de Resolución de Incidentes y Preguntas Frecuentes

Síntoma / Incidencia Causa Raíz Solución Técnica Inmediata
"Directiva de ejecución restringida" en PowerShell La directiva global de Windows prohíbe scripts .ps1. Ejecute siempre los scripts mediante los archivos .bat provistos, los cuales aplican -ExecutionPolicy Bypass automáticamente sin alterar la seguridad del equipo.
PostgreSQL se instaló en el puerto 5433 Coexistencia con otra instancia o instalador de EnterpriseDB. El instalador detecta automáticamente si el puerto 5433 está escuchando y lo sugiere por defecto; solo presione Enter al configurar la base de datos.
El puerto 3000 o 4000 aparece ocupado Instancia previa de Node.js o proceso huérfano activo. Haga doble clic en Detener_Congreso.bat para liberar los puertos de inmediato.
Error "No existe la columna capacidad_maxima" Base de datos previa desactualizada o migración incompleta. Ejecute Reparar_BaseDatos.bat en la raíz. La utilidad añadirá las columnas faltantes y regularizará las claves foráneas sin pérdida de datos.
El escáner QR en celulares no conecta con la PC Bloqueo del Firewall de Windows en la red Wi-Fi local. Habilite las reglas de entrada para los puertos 3000 y 4000 en el Firewall de Windows Defender según se explica en la Sección 2.3.
