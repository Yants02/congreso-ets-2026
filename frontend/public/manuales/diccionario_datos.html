Módulo 1: Identidad, Roles y Usuarios Autenticación & RBAC

Gobierna las credenciales de asistentes, disertantes, operadores y personal directivo DETS. Gestiona la jerarquía de roles, estados del ciclo de vida de la preinscripción y cuentas con credenciales de acceso administrativo.

roles
Clave Primaria: id (SERIAL) Registros Base: 8 jerarquías
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id SERIAL NOT NULL PK Identificador numérico autoincremental del rol.
nombre VARCHAR(50) NOT NULL UNIQUE Nombre único del rol (Estudiante, Docente, Expositor, Autoridad, Operador, Verificador, Administrador, Superadmin).
descripcion TEXT NULL - Explicación de las facultades y perfil del usuario.
jerarquia INTEGER NOT NULL DEFAULT 1 - Nivel numérico de autorización para el middleware requerirJerarquia(N): 1: Asistente/Estudiante, 2: Expositor/Autoridad, 3: Operador acreditador, 4: Administrador/Verificador, 5: Superadmin.
creado_en TIMESTAMPTZ DEFAULT NOW() - Marca temporal de creación del rol.
estados_inscripcion
Clave Primaria: id (SERIAL) Normalización: Catálogo maestro de aforos
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id SERIAL NOT NULL PK Identificador autoincremental del estado de inscripción.
codigo VARCHAR(30) NOT NULL UNIQUE Código nemotécnico: CONFIRMADO, LISTA_ESPERA, SANCIONADO, BAJA_AUTOMATICA, CANCELADO.
nombre VARCHAR(50) NOT NULL - Etiqueta amigable legible en interfaces de usuario.
permite_ingreso BOOLEAN NOT NULL DEFAULT FALSE - Flag booleano consultado por la PWA en puerta. Solo TRUE si el código es CONFIRMADO.
descripcion TEXT NULL - Regla operativa asociada a la categoría de inscripción.
usuarios
Clave Primaria: id (UUID) Restricción: UNIQUE (dni_pasaporte, evento_id)
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id UUID NOT NULL DEFAULT gen_random_uuid() PK Identificador global universal del participante (UUID v4).
dni_pasaporte VARCHAR(50) NOT NULL UQ COMP Documento de identidad. No puede repetirse para el mismo evento_id.
evento_id INTEGER NOT NULL DEFAULT 1 FK Referencia foránea a eventos(id). Permite multi-evento temporal.
nombre VARCHAR(100) NOT NULL - Nombre de pila del asistente.
apellido VARCHAR(100) NOT NULL - Apellido del asistente.
email VARCHAR(150) NOT NULL - Dirección de correo para notificaciones, confirmaciones y certificados.
celular VARCHAR(30) NOT NULL - Número de contacto telefónico / WhatsApp.
rol_principal_id INTEGER NOT NULL FK Referencia a roles(id) asignado durante la inscripción.
estado_inscripcion_id INTEGER NOT NULL FK Referencia a estados_inscripcion(id) (calculado por cupo FIFO o blacklist).
foto_url TEXT NULL - Ruta relativa o URI de la fotografía para la credencial oficial.
foto_metadata JSONB NULL - Dimensiones, peso, hash SHA-256 o estado de moderación de la imagen.
creado_en TIMESTAMPTZ DEFAULT NOW() - Fecha y hora exacta de la preinscripción inicial.
actualizado_en TIMESTAMPTZ DEFAULT NOW() - Marca temporal de la última actualización del registro.
usuario_roles_adicionales
Clave Primaria Compuesta: (usuario_id, rol_id) Relación: N:M Usuarios y Roles
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
usuario_id UUID NOT NULL PK FK Referencia a usuarios(id) con borrado en cascada (ON DELETE CASCADE).
rol_id INTEGER NOT NULL PK FK Referencia a roles(id) asignado adicionalmente.
asignado_en TIMESTAMPTZ DEFAULT NOW() - Marca temporal en que se confirió el rol secundario.
operadores
Clave Primaria: id (SERIAL) Seguridad: PBKDF2-SHA512 + Salting
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id SERIAL NOT NULL PK Identificador numérico autoincremental del operador.
nombre VARCHAR(100) NOT NULL - Nombre del operador o funcionario asignado.
apellido VARCHAR(100) NOT NULL - Apellido del operador.
email_institucional VARCHAR(150) NOT NULL UNIQUE Correo oficial GCABA utilizado como nombre de usuario para iniciar sesión.
punto_acceso_default_id INTEGER NOT NULL FK Referencia a puntos_acceso(id) asignado por defecto para check-ins rápidos.
rol_id INTEGER NOT NULL DEFAULT 5 FK Referencia a roles(id) que define el nivel jerárquico operativo.
password_hash VARCHAR(255) NULL - Hash criptográfico de contraseña con formato [salt_hex]:[hash_pbkdf2_hex].
activo BOOLEAN NOT NULL DEFAULT TRUE - Permite inhabilitar el acceso al panel sin destruir registros de auditoría históricos.
creado_en TIMESTAMPTZ DEFAULT NOW() - Marca temporal de alta del operador.

Módulo 2: Eventos, Puntos de Acceso y Actividades Gestión de Agenda & Salas

Administra las sedes físicas, puertas de acceso, ediciones anuales del congreso, catálogo pedagógico de talleres, asignación horaria y control de aforo por sala.

eventos
Clave Primaria: id (SERIAL) Capacidad: Multi-evento y Ediciones Anuales
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id SERIAL NOT NULL PK Identificador numérico de la edición o congreso.
codigo VARCHAR(50) NOT NULL UNIQUE Código alfanumérico identificador único (ej: ETS_2026, ETS_2027).
nombre VARCHAR(150) NOT NULL - Nombre institucional completo del congreso o jornada.
lema VARCHAR(250) NULL - Lema o subtítulo pedagógico rector de la edición.
descripcion TEXT NULL - Memoria descriptiva de objetivos y alcances.
anio INTEGER NOT NULL - Año lectivo calendario de celebración.
fecha_inicio DATE NOT NULL - Fecha de inicio formal del evento.
fecha_fin DATE NOT NULL - Fecha de finalización y entrega de certificaciones.
cupo_maximo INTEGER NOT NULL DEFAULT 400 - Aforo total permitido del predio para bloqueo pesimista en registrar_usuario_seguro.
estado VARCHAR(30) NOT NULL DEFAULT 'PUBLICADO' - Estado: EN_PLANIFICACION, PUBLICADO, EN_CURSO, FINALIZADO, ARCHIVADO.
activo BOOLEAN NOT NULL DEFAULT TRUE - Indica si el evento es el predeterminado para el registro público.
puntos_acceso
Clave Primaria: id (SERIAL) Normalización 3FN: Desacople de puertas y terminales
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id SERIAL NOT NULL PK Identificador del punto físico de control.
evento_id INTEGER NULL FK Referencia a eventos(id) con ON DELETE CASCADE.
nombre VARCHAR(100) NOT NULL - Nombre identificador del acceso (ej: Puerta Principal Hall PB).
ubicacion_fisica VARCHAR(150) NOT NULL - Referencia espacial en el plano del edificio sede.
tipo_punto VARCHAR(30) NOT NULL DEFAULT 'PUESTO_ACCESO' - Tipo: PUESTO_ACCESO, SALA_CONFERENCIA, AULA_TALLER, ESPACIO_NETWORKING.
activo BOOLEAN NOT NULL DEFAULT TRUE - Estado de habilitación del puesto para escaneo óptico.
tipos_acreditacion
Clave Primaria: id (SERIAL) Propósito: Tipología y permisos de paso
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id SERIAL NOT NULL PK Identificador numérico del tipo de acreditación.
codigo VARCHAR(50) NOT NULL UNIQUE Código unívoco: ACCESO_GENERAL, ACTIVIDAD_AULA, TALLER, MASTERCLASS.
descripcion VARCHAR(150) NOT NULL - Descripción del permiso y nivel de acceso otorgado.
requiere_actividad BOOLEAN NOT NULL DEFAULT FALSE - Exige que el asistente esté previamente inscripto a la actividad para conceder paso.
catalogo_actividades
Clave Primaria: id (SERIAL) Propósito: Oferta pedagógica reutilizable
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id SERIAL NOT NULL PK Identificador numérico autoincremental de la propuesta.
codigo VARCHAR(50) NOT NULL UNIQUE Código pedagógico oficial de la temática (ej: TALLER_CIBERDEF).
nombre VARCHAR(150) NOT NULL - Título oficial del taller, panel o conferencia magistral.
descripcion TEXT NULL - Contenidos mínimos, requerimientos previos y objetivos pedagógicos.
tipo_acreditacion_id INTEGER NOT NULL FK Referencia a tipos_acreditacion(id).
categoria_tematica_id INTEGER NULL FK Referencia a categorias_tematicas(id) (eje temático del Congreso).
horas_catedra INTEGER NOT NULL DEFAULT 2 - Carga horaria acreditada para cómputo de certificados.
activo BOOLEAN NOT NULL DEFAULT TRUE - Disponibilidad para ser programada en las salas del evento.
actividades
Clave Primaria: id (SERIAL) Restricción: Validación contra solapamiento temporal (ConflictEngine)
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id SERIAL NOT NULL PK Identificador numérico de la sesión o actividad programada.
evento_id INTEGER NOT NULL FK Referencia a eventos(id) con ON DELETE CASCADE.
nombre VARCHAR(150) NOT NULL - Denominación de la sesión o panel específico.
descripcion TEXT NULL - Resumen de la disertación o contenido de la mesa redonda.
tipo_acreditacion_id INTEGER NOT NULL FK Referencia a tipos_acreditacion(id).
punto_acceso_id INTEGER NOT NULL FK Referencia a puntos_acceso(id) (aula o auditorio donde se dicta).
cupo_maximo INTEGER NOT NULL DEFAULT 50 - Capacidad física de butacas o puestos disponibles para la actividad.
horario_inicio TIMESTAMPTZ NOT NULL - Inicio programado de la sesión.
horario_fin TIMESTAMPTZ NOT NULL - Finalización programada de la sesión.
disertante_nombre VARCHAR(150) NULL - Nombre del expositor, moderador o panelista a cargo.
activo BOOLEAN NOT NULL DEFAULT TRUE - Visibilidad en la grilla horaria pública.
actividad_inscripciones
Clave Primaria: id (SERIAL) Regla: Aforo estricto y prevención de solapamiento
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id SERIAL NOT NULL PK Identificador numérico autoincremental del cupo asignado.
actividad_id INTEGER NOT NULL FK Referencia foránea a actividades(id).
usuario_id UUID NOT NULL FK Referencia foránea a usuarios(id).
estado VARCHAR(30) NOT NULL DEFAULT 'CONFIRMADO' - Estado: CONFIRMADO (titular), LISTA_ESPERA (en cola FIFO), CANCELADO.
creado_en TIMESTAMPTZ DEFAULT NOW() - Marca de tiempo para el orden de prelación en lista de espera.

Módulo 3: Acreditaciones, Control en Puerta y Seguridad PWA Offline & Criptografía QR

Registra los movimientos físicos de ingreso y egreso en los puntos de control, la intercepción automática de sanciones disciplinarias (Blacklist), la homologación de pergaminos de disertantes y los tokens de reconfirmación de 48 horas.

acreditaciones
Clave Primaria: id (UUID) Rendimiento: Índices compuestos para Anti-Passback
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id UUID NOT NULL DEFAULT gen_random_uuid() PK Identificador universal único e inmutable del check-in.
usuario_id UUID NOT NULL FK Referencia a usuarios(id) con ON DELETE CASCADE.
operador_id INTEGER NOT NULL FK Referencia a operadores(id) que validó el ingreso en la estación.
tipo_acreditacion_id INTEGER NOT NULL FK Referencia a tipos_acreditacion(id).
actividad_id INTEGER NULL FK Referencia a actividades(id) (solo si se acredita acceso a taller específico).
punto_acceso_id INTEGER NOT NULL FK Referencia a puntos_acceso(id) donde se produjo la lectura física.
es_manual BOOLEAN NOT NULL DEFAULT FALSE - Indica si el check-in fue por contingencia sin lectura óptica directa de QR.
motivo_manual TEXT NULL - Justificación asentada por el operador (ej: Gafete extraviado, validado por DNI físico).
tipo_movimiento VARCHAR(20) NOT NULL DEFAULT 'INGRESO' - Dirección del paso físico: INGRESO o EGRESO (Control Anti-Passback).
timestamp_acreditacion TIMESTAMPTZ DEFAULT NOW() - Marca temporal exacta del escaneo óptico o sincronización PWA offline.
blacklist
Clave Primaria: id (SERIAL) Integridad: Intercepción en tiempo real por Trigger
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id SERIAL NOT NULL PK Identificador numérico del registro disciplinario.
dni_pasaporte VARCHAR(50) NOT NULL UNIQUE Número de documento sancionado o restringido.
motivo TEXT NOT NULL - Fundamentación institucional o resolución ministerial de sanción.
registrado_por VARCHAR(100) DEFAULT 'SISTEMA' - Nombre o correo del funcionario/auditor que ordenó la inclusión.
registrado_en TIMESTAMPTZ DEFAULT NOW() - Fecha y hora del registro disciplinario.
activo BOOLEAN NOT NULL DEFAULT TRUE - Vigencia de la sanción. Si se desactiva, el asistente puede volver a inscribirse.
confirmaciones_asistencia
Clave Primaria: id (SERIAL) Mecanismo: Liberación automática de cupos 48hs
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id SERIAL NOT NULL PK Identificador numérico del token de reconfirmación.
usuario_id UUID NOT NULL FK Referencia a usuarios(id) con ON DELETE CASCADE.
token_hash VARCHAR(128) NOT NULL UNIQUE Hash criptográfico SHA-256 remitido en el hipervínculo del correo de aviso 48hs.
emitido_en TIMESTAMPTZ DEFAULT NOW() - Marca temporal de emisión del correo de reconfirmación.
expira_en TIMESTAMPTZ NOT NULL - Límite estricto de confirmación (típicamente 24 horas tras la emisión).
confirmado_en TIMESTAMPTZ NULL - Instante en el que el asistente pulsó el botón confirmando su asistencia.
ip_confirmacion VARCHAR(45) NULL - Dirección IPv4/IPv6 de origen para trazabilidad y auditoría.
homologaciones_expositores
Clave Primaria: id (SERIAL) Módulo: Validación documental de disertantes
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id SERIAL NOT NULL PK Identificador numérico del trámite de homologación.
usuario_id UUID NOT NULL FK UQ Referencia foránea unívoca al expositor en usuarios(id).
estado_homologacion VARCHAR(30) NOT NULL DEFAULT 'PENDIENTE' - Estado: PENDIENTE, VALIDADO, RECHAZADO, ANULADO.
documentacion_presentada TEXT NULL - Detalle o enlace al pergamino, CV o título académico acreditado.
observaciones TEXT NULL - Anotaciones técnicas del funcionario auditor.
funcionario_validador_id INTEGER NULL FK Referencia a operadores(id) que certificó la autenticidad del expositor.
fecha_validacion TIMESTAMPTZ NULL - Instante en el que se concedió la homologación oficial.
motivo_anulacion TEXT NULL - Causal de rechazo o revocación en caso de irregularidad.

Módulo 4: Certificación Digital y Diplomas Vectorial PDF-Lib & Hash SHA-256

Almacena el registro fehaciente de los diplomas oficiales emitidos por el motor de PDF vectorial dinámico. Cada credencial cuenta con código de verificación criptográfica y enlace público de validación inmediata.

certificados
Clave Primaria: id (UUID) Restricción: UNIQUE (usuario_id, tipo_certificado)
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id UUID NOT NULL DEFAULT gen_random_uuid() PK Identificador único inmutable del diploma emitido.
codigo_verificacion VARCHAR(50) NOT NULL UNIQUE Hash alfanumérico SHA-256 único incrustado en el QR del diploma para validación en línea.
usuario_id UUID NOT NULL FK UQ COMP Referencia a usuarios(id) con ON DELETE CASCADE.
evento_id INTEGER DEFAULT 1 FK Referencia a eventos(id).
tipo_certificado VARCHAR(50) NOT NULL DEFAULT 'ASISTENCIA' UQ COMP Modalidad: ASISTENCIA, EXPOSITOR, DISERTANTE, ORGANIZADOR.
horas_catedra INTEGER NOT NULL DEFAULT 16 - Carga horaria académica certificada para puntaje docente o curricular.
emitido_en TIMESTAMPTZ DEFAULT NOW() - Fecha y hora oficial de emisión del certificado.
metadata JSONB NULL - Snapshot de autoridades firmantes, texto del diploma y versión de la plantilla utilizada.

Módulo 5: Encuestas Dinámicas y Métricas de Satisfacción Bloqueo Pedagógico & Diseñador WYSIWYG

Sustenta el Diseñador Visual WYSIWYG de Encuestas. Estructura baterías de preguntas de opciones múltiples, estrellas y respuestas abiertas, garantizando la recolección de métricas de calidad y la restricción pedagógica de descarga de diplomas.

categorias_tematicas
Clave Primaria: id (SERIAL) Propósito: Ejes temáticos del Congreso
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id SERIAL NOT NULL PK Identificador numérico de la categoría temático-académica.
nombre VARCHAR(100) NOT NULL UNIQUE Denominación del eje (ej: Inteligencia Artificial y Machine Learning).
descripcion TEXT NULL - Alcance del área tecnológica e impacto curricular.
activo BOOLEAN NOT NULL DEFAULT TRUE - Habilita la categoría para asignación en talleres y preguntas.
encuestas
Clave Primaria: id (SERIAL) Regla Clave: Bloqueo pedagógico de diplomas
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id SERIAL NOT NULL PK Identificador numérico autoincremental de la encuesta.
evento_id INTEGER NOT NULL FK Referencia a eventos(id) con ON DELETE CASCADE.
titulo VARCHAR(150) NOT NULL - Título descriptivo de la evaluación (ej: Evaluación de Satisfacción Institucional ETS 2026).
descripcion TEXT NULL - Instrucciones de llenado y agradecimiento al participante.
etapa VARCHAR(50) NOT NULL DEFAULT 'INSCRIPCION' - Fase: INSCRIPCION, CONFIRMACION, ACREDITACION, POST_EVENTO, SONDEO_ABIERTO.
es_obligatoria BOOLEAN NOT NULL DEFAULT FALSE - Si es TRUE, el motor de certificados bloquea la descarga del diploma hasta que se asiente la respuesta.
activa BOOLEAN NOT NULL DEFAULT TRUE - Habilita la visualización y respuesta activa en el portal del asistente.
encuesta_preguntas
Clave Primaria: id (SERIAL) WYSIWYG: Tipología configurable (estrellas, radio, texto)
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id SERIAL NOT NULL PK Identificador numérico autoincremental del ítem.
encuesta_id INTEGER NOT NULL FK Referencia a encuestas(id) con borrado en cascada.
categoria_tematica_id INTEGER NULL FK Referencia a categorias_tematicas(id) para análisis segmentado.
orden INTEGER NOT NULL DEFAULT 1 - Secuencia ordinal de presentación en el formulario reactivo.
texto_pregunta TEXT NOT NULL - Consigna o pregunta visible formulada al asistente.
tipo_pregunta VARCHAR(50) NOT NULL DEFAULT 'OPCION_MULTIPLE' - Tipos admitidos: OPCION_UNICA, OPCION_MULTIPLE, CALIFICACION_1_A_5, TEXTO_ABIERTO.
es_obligatoria BOOLEAN NOT NULL DEFAULT FALSE - Indica si el asistente puede omitir la respuesta al enviar el cuestionario.
peso_ponderacion NUMERIC(4,2) DEFAULT 1.00 - Factor de ponderación matemática para cómputo de métricas agregadas.
encuesta_opciones
Clave Primaria: id (SERIAL) Propósito: Opciones seleccionables de preguntas cerradas
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id SERIAL NOT NULL PK Identificador numérico autoincremental de la alternativa.
pregunta_id INTEGER NOT NULL FK Referencia a encuesta_preguntas(id) con ON DELETE CASCADE.
orden INTEGER NOT NULL DEFAULT 1 - Orden de aparición en la lista de opciones.
texto_opcion VARCHAR(250) NOT NULL - Texto de la opción de respuesta (ej: Excelente, Muy Bueno, Regular).
valor_ponderacion NUMERIC(4,2) DEFAULT 1.00 - Puntaje ponderado asignado a la elección.
encuesta_respuestas
Clave Primaria: id (UUID) Restricción: UNIQUE (encuesta_id, usuario_id)
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id UUID NOT NULL DEFAULT gen_random_uuid() PK Identificador universal del envío completado de la encuesta.
encuesta_id INTEGER NOT NULL FK UQ COMP Referencia a encuestas(id) con ON DELETE CASCADE.
usuario_id UUID NULL FK UQ COMP Referencia a usuarios(id). Impide envíos duplicados por participante.
ip_origen VARCHAR(45) NULL - Dirección IP del cliente al momento de completar la encuesta.
creado_en TIMESTAMPTZ DEFAULT NOW() - Marca temporal de registro y desbloqueo del certificado.
encuesta_respuestas_detalles
Clave Primaria: id (BIGSERIAL) Normalización 3FN: Desglose atómico de respuestas
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id BIGSERIAL NOT NULL PK Identificador autoincremental de 64 bits de la respuesta individual.
respuesta_id UUID NOT NULL FK Referencia a la cabecera en encuesta_respuestas(id) con borrado en cascada.
pregunta_id INTEGER NOT NULL FK Referencia a encuesta_preguntas(id).
opcion_id INTEGER NULL FK Referencia a encuesta_opciones(id) (en caso de preguntas de opción múltiple/única).
valor_numerico INTEGER NULL - Puntaje numérico asignado (en preguntas de estrellas 1 a 5).
respuesta_texto TEXT NULL - Devolución cualitativa abierta redactada por el participante.

Módulo 6: Configuración del Sistema, Push y Auditoría Gobernanza & Trazabilidad

Mantiene los parámetros operativos y plantillas en formato JSONB, las suscripciones Web Push conforme al estándar VAPID (RFC 8292) y la bitácora inmutable de auditoría forense.

configuraciones_sistema
Clave Primaria: clave (VARCHAR 100) Estructura: Almacén NoSQL flexible JSONB
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
clave VARCHAR(100) NOT NULL PK Nombre identificador del parámetro del sistema (ej: plantilla_certificado_oficial, smtp_google, aforo_maximo_confirmados).
valor JSONB NOT NULL - Estructura JSON binaria con los parámetros dinámicos, fuentes, firmantes y credenciales.
descripcion TEXT NULL - Documentación funcional de la configuración para administradores.
categoria VARCHAR(50) DEFAULT 'GENERAL' - Agrupación operativa: GENERAL, CERTIFICADOS, CORREO, BACKUP, SEGURIDAD.
actualizado_en TIMESTAMPTZ DEFAULT NOW() - Marca temporal de la última modificación en la tabla.
suscripciones_push
Clave Primaria: id (SERIAL) Estándar: VAPID Web Push (RFC 8292)
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id SERIAL NOT NULL PK Identificador numérico autoincremental de la suscripción.
usuario_id UUID NULL FK Referencia opcional a usuarios(id) para notificaciones personalizadas.
endpoint TEXT NOT NULL UNIQUE URI del servicio de mensajería Push de los navegadores (Google FCM, Mozilla Push, etc.).
p256dh TEXT NOT NULL - Clave pública ECDH para cifrado de los payloads de aviso push.
auth TEXT NOT NULL - Secreto de autenticación del cliente push.
creado_en TIMESTAMPTZ DEFAULT NOW() - Fecha y hora de suscripción a avisos del navegador.
logs_auditoria
Clave Primaria: id (BIGSERIAL) Gobernanza: Inmutabilidad forense absoluta
Campo Tipo de Dato Modificador Clave Descripción / Regla de Negocio
id BIGSERIAL NOT NULL PK Identificador autoincremental de 64 bits para alta concurrencia de eventos.
evento VARCHAR(100) NOT NULL - Tipo de operación auditada: LOGIN_OPERADOR, CHECKIN_ACREDITACION, CAMBIO_PLANTILLA_CERTIFICADO, SYNC_ENCUESTA, OVERRIDE_SOBRECUPO.
actor_usuario VARCHAR(100) NOT NULL - Correo o identificador del operador o subsistema que ejecutó la mutación.
usuario_afectado_id UUID NULL FK Referencia opcional a usuarios(id) sujeto de la acción.
detalles JSONB NULL - Fotografía de datos previos y nuevos, campos modificados o respuesta del servidor.
ip_origen VARCHAR(45) NULL - Dirección IP remota del cliente desde donde se originó la petición.
timestamp TIMESTAMPTZ DEFAULT NOW() - Marca temporal exacta e inmutable de asentamiento forense.
Garantía de Normalización en 3FN: Todas las tablas han sido auditadas para eliminar dependencias funcionales transitivas y garantizar que cada atributo no-clave dependa directa y exclusivamente de la clave primaria completa, asegurando la consistencia e integridad de datos ante cualquier operación transaccional concurrente.
